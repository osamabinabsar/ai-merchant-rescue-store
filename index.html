Frequently asked questions

Is this a subscription?

No. You buy the ZIP once and keep it. Multi-account or multi-case upgrades are billed separately if you need them.

Do I need a specific AI tool?

No. The scripts run directly with Python. The folders also work as skills inside Claude Code, Codex, Cursor, Hermes, and similar agents because they include SKILL.md, but that is optional.

Will my data be uploaded anywhere?

No. Everything runs locally. Still, read the scripts before running them on sensitive data; that is good practice for any downloaded code.

What format do my statements need to be in?

Merchant Fee Audit and Bookkeeping Rescue accept CSV, OFX, JSON, and pasted PDF text. Small cleanup is expected because banks export messy data.

Are there refunds?

Digital goods are generally non-refundable because you receive the full files. If a product is broken on your machine, email and we will fix it or refund. This is a starting-from-zero shop run by a small team, so expect human replies, not a ticket system.

Why is this page so plain?

Because we would rather ship a working tool than a glossy landing page. No fake screenshots, no rented testimonials, no countdown timers. When revenue and real feedback exist, we will publish them honestly.
